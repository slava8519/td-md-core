# Tersoff-Si frozen golden — `pair_style tersoff run 0`

The LOAD-BEARING external witness for the Tersoff bond-order potential (Te1). Unlike SW —
where the all-triplets oracle shares only the *enumeration* with the checked path, so
FD-of-energy is an independent algebra witness — a Tersoff force-recomputation oracle shares
the `b_ij` derivative algebra, so **FD-of-energy + this LAMMPS golden are the ONLY independent
witnesses of the derivative algebra** (and the only witness of the parameter traps below).
CI is **LAMMPS-free** — the test (`Test_Tersoff_LAMMPS`) reads these frozen files.

## Files
- `tersoff_si_64.data` — diamond-cubic Si, 64 atoms (2×2×2, a₀=5.431 Å), perturbed
  (`gen::make_diamond_si(2,2,2,5.431,0.20,seed=12345)`) so the angular bond-order is exercised.
  Fully periodic; box ≈ 10.862³ Å (> 2·rcut = 6.4 Å, min-image unambiguous).
- `tersoff_si_64.forces` — `PE` (eV) + per-atom forces (eV/Å) from `pair_style tersoff run 0`.
- `gen_forces.in` — the LAMMPS regeneration script (place `Si.tersoff` + `tersoff_si_64.data`
  in the CWD; `tersoff_si_64.data` is regenerated by `tools/tersoff_lammps_check.cpp`).

## Provenance
- LAMMPS stable 22Jul2025 (MANYBODY), `pair_style tersoff`, potential `Si.tersoff`
  (canonical Tersoff-1988 Si — column order `m γ λ₃ c d cosθ₀ n β λ₂ B R D λ₁ A`):
  `m=3, γ=1.0, λ₃=1.3258, c=4.8381, d=2.0417, h≡cosθ₀=0.0, n=22.956, β=0.33675, λ₂=1.3258,
  B=95.373, R=3.0, D=0.2, λ₁=3.2394, A=3264.7`.

## Measured agreement (the gate's basis, NOT pre-registered)
- PE: ours −276.2538631431167 vs LAMMPS −276.253863143117 (Δ ≈ 1e-13 eV).
- forces: max|F_ours − F_lammps| = **4.26e-14 eV/Å** (max |F| = 9.87 eV/Å) — the helpers are
  replicated character-for-character from `pair_tersoff.cpp` (the 5-branch `b_ij` guard, the
  ±69.0776 exp clamp, both sign conventions). The gate is kept at 1e-9 for cross-build margin;
  NOT a bitwise-to-LAMMPS claim. The two parameter traps only this golden catches (FD is blind):
  **T-a** `h≡cosθ₀` lives inside `g`, not a cutoff; **T-b** `h(r)=exp(λ₃^m(r_ij−r_ik)^m)` with
  m=3 odd ⇒ sign-sensitive `λ₃³` (for Si λ₃=λ₂ numerically — a swap is masked; full
  discrimination needs a multi-element golden, deferred).
