# SW-Si frozen golden — Stillinger–Weber `pair_style sw run 0`

External validation reference for the Stillinger–Weber angular potential (SW-ladder T7).
CI is **LAMMPS-free** — these files are the frozen LAMMPS reference; the test
(`Test_SW_LAMMPS`) reads them and compares our `sw_direct_fp64`.

## Files
- `sw_si_64.data` — diamond-cubic Si, 64 atoms (2×2×2 conventional cells, a₀=5.431 Å),
  deterministically perturbed (`gen::make_diamond_si(2,2,2,5.431,0.20,seed=12345)`) so the
  angular φ₃ term is exercised (a perfect lattice sits at the tetrahedral angle ⇒ φ₃≈0).
  Fully periodic; box ≈ 10.862³ Å (> 2·rcut = 7.54 Å, min-image unambiguous).
- `sw_si_64.forces` — `PE` (eV) + per-atom forces (eV/Å) from LAMMPS `pair_style sw run 0`
  (`Test_SW_LAMMPS`).
- `sw_rdf_216.data` — 216-atom (3×3×3) diamond-Si, box 16.293³ Å, equilibrated at 600 K +
  **with velocities** (a single NVE snapshot at step 1000 — its *instantaneous* T fluctuates
  around 600 K, ≈676 K, NOT thermostatted). The starting config for our NVE RDF run.
- `sw_rdf_lammps.gr` — LAMMPS time-averaged g(r), 80 bins to cutoff a·σ=3.7712 Å, fix
  ave/time over the 1000 NVE steps (`Test_SW_RDF`, cosine overlap of our g(r)).
- `gen_forces.in` / `gen_rdf.in` — the LAMMPS scripts that regenerate the two goldens
  (run with `lmp -in <script>` after placing `Si.sw` in the CWD; gen_forces.in also needs
  `sw_si_64.data`, generated by `tools/sw_lammps_check.cpp`).

## Provenance
- LAMMPS stable 22Jul2025 (MANYBODY), `pair_style sw`, potential `Si.sw` (the canonical
  Stillinger–Weber Si: ε=2.1683, σ=2.0951, a=1.80, λ=21.0, γ=1.20, cosθ₀=−1/3,
  A=7.049556277, B=0.6022245584, p=4, q=0).
- Generated by `tools/sw_lammps_check.cpp` (writes the `.data` + our forces) + a `run 0`
  with `dump_modify format float %.16e sort id`.

## Measured agreement (the gate's basis, NOT pre-registered)
- PE: ours −252.9945896232709 vs LAMMPS −252.994589623268 (Δ ≈ 3e-11 eV).
- forces: max|F_ours − F_lammps| = **1.03e-12 eV/Å** (max |F| = 7.55 eV/Å) — the exp/pow
  ulp difference (libm vs LAMMPS), the form + parameters are otherwise exact.
- Gate tolerances are kept ×1000 looser (PE < 1e-6, force < 1e-9) for cross-build /
  FP-contraction margin — this is NOT a bitwise-to-LAMMPS claim (transcendentals differ).
- RDF: the time-averaged g(r) from our NVE trajectory cosine-overlaps LAMMPS's at **0.999815**
  (nn-peak 6.53 vs 6.64). g(r) is an equilibrium ensemble average — our trajectory
  Lyapunov-diverges from LAMMPS's, but the AVERAGED curves coincide (the structure dimension;
  the precision dimension is the forces golden above).
